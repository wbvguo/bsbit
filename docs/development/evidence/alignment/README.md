# Alignment benchmark evidence

This Git-tracked directory contains small, durable alignment benchmark records
selected for ongoing comparison and documentation. Each record should include
reproduction commands, the source revision, input identity, host and CPU scope,
repetitions, correctness checks, and a concise conclusion.

Keep large raw outputs in `../../../../workspace/runs/` or the originating
`../../../../workspace/worktree/` attempt. Repository documentation may link to
records here because this directory is available in a clean checkout. Do not
rewrite an existing record when a new measurement supersedes it; add a new
dated record.
